08FAQ

Frequently asked questions

Everything you need to know about the scan, flags and resolution.

What does a Chainscaner check actually scan?
Each check performs a read-only pass across 12 networks: balances and token holdings, dust and spam remnants, active approvals, sanctions and mixer proximity, bridge and cross-hop traces, and gas readiness. No transaction is ever created and no signature is requested.
Is the free check really free?
Yes — one full check per wallet is free, no card or account required. On-chain flag resolution is a Pro Session (€249) that adds deep chain analysis, compliance attestation and a tracked session link.
Do I need to connect a wallet or share a private key?
No. Scans are computed entirely from public ledger state. You only paste an address — private keys are never requested, and a scan can never move funds.
What does a flag mean — and how is it resolved?
Flags mark proximity to sanctioned entities, mixers, darknet clusters, or reported scam and drainer addresses. Resolution re-traces the funding path, separates true exposure from false positives such as dust attacks or shared exchange wallets, and documents the outcome in the report.
Which networks and address types are supported?
12 networks including Ethereum, BNB Chain, Polygon, Arbitrum, Optimism, Base, Avalanche, Celo, Fantom, Cronos, Linea and Scroll — plus TRON endpoints. Both EVM 0x addresses and TRON base58 addresses are accepted.
Is there an API for programmatic access?
Yes — a free read-only JSON API is documented at chainscaner.com/docs. It returns balances, token exposure, approvals and reputation flags; no API key is required for read access during beta.
