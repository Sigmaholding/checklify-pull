About & Methodology

ChainScanner is a read-only address intelligence service. Given any wallet address, it produces a cross-network report of balances, token holdings, active approval exposure and reputation flags — the same data a block explorer shows, aggregated across chains in a single pass.

What a scan does

EVM addresses (0x…) are queried in parallel across Ethereum, Base, Polygon, Arbitrum, Optimism and BNB Chain:

  • Native balance via public JSON-RPC nodes
  • Full ERC-20 holdings via public indexer data, including dust and spam-token detection
  • Active token allowances toward known spender contracts (DEX routers, Permit2) verified on-chain
  • USD valuation via public market pricing

TRON addresses (T…) return account status, TRX balance, energy allocation, TRC-20 holdings and USDT allowance data from network nodes.

Every address, held token contract and spender is matched against the ChainScanner flag database — a curated list of reported scam, drainer and phishing entities.

Data sources

  • Public blockchain RPC nodes (balances, allowances, contract reads)
  • Public indexer data (token holdings, metadata, token reputation)
  • Public market pricing for USD valuation
  • ChainScanner flag database (operator-reviewed reports)

All sources are public ledger data. Results are cached for 5 minutes.

Limitations

Approval checks cover known major spender contracts; a complete historical allowance audit requires archival indexers and is on the roadmap. Dust marking applies to positions under $0.01. A "clean" result is not a guarantee — always verify counterparties independently.
