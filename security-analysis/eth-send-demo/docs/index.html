API Reference

All endpoints are read-only JSON over HTTPS. No authentication is required for read access. Responses are served from chainscaner.com/api/tronread. Scan results are cached server-side for 5 minutes.

Multi-chain address scan

POST /api/tronread

Returns native balances, detected token holdings (with USD valuation, dust and spam marking), active token approvals toward known spender contracts, and reputation flags across 6 EVM networks.

TRON endpoints

Request bodyReturns
{"account":"T…"}Account state, TRX balance, available energy
{"trx":"T…"}TRX balance (SUN)
{"owner":"T…","token":"usdt"}TRC-20 balance
{"owner":"T…","spender":"T…","token":"usdt"}Token balance + current allowance

Reputation flags

Request bodyReturns
{"flags":1}Full public flag list
{"flag":"0x…"|"T…"}Single-address lookup
{"flagsIn":["0x…","T…"]}Batch lookup (max 60)

Flag entries contain reason, sev (low / high / critical) and a timestamp.

Fair use

The service is free during beta. Please keep request rates reasonable; abusive clients may be throttled. All queries are read-only — the API never creates or broadcasts transactions.
