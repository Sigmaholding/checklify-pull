Privacy Policy

Effective date: 2025. ChainScanner provides read-only lookups of public blockchain data.

Data we process

  • Wallet addresses you submit — queried against public TRON network nodes to return balances and account metadata. Addresses are public blockchain identifiers, not personal data.
  • Technical request data — standard server logs (IP, user agent, timestamps) for abuse prevention and rate limiting, retained briefly.
  • Reputation list — an operator-curated list of addresses and token contracts flagged during security review.

What we never collect

  • Private keys, seed phrases, or wallet credentials — never enter them on this site.
  • Personal identity information; no accounts exist on this service.
  • Cookies for tracking or advertising; the service sets no third-party trackers.

On-chain results

Scan output is assembled from public ledger state via read-only calls. No scan creates a blockchain transaction.

Changes

We may update this policy; the current version is always published at this address.
